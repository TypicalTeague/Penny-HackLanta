# Devpost description

## Penny — an iMessage-first robo-investor

Penny is for beginners who want investing handled for them without learning portfolio construction, diversification, monitoring, and rebalancing first. A user tells Penny what is happening in their life, chooses Low, Medium, or High risk, and approves a mandate. Penny protects near-term needs, creates a diversified paper portfolio, manages it automatically, sends visual weekly updates, and proposes safe changes after raises, bonuses, rent increases, tuition bills, or emergency repairs.

The entire experience lives in iMessage through Photon Spectrum: typing indicators, tapbacks, threaded replies, native polls, generated portfolio-card attachments, and proactive updates. Gemini converts natural language into schema-validated facts but cannot make financial decisions. Deterministic TypeScript engines calculate capacity, allocate exact cents, apply reproducible market movement, detect drift, and rebalance. PostgreSQL provides durable, user-isolated memory and an auditable history. Auth0’s hosted Device Authorization flow verifies consequential approvals without a custom website.

The HackLanta build is entirely simulated: no deposits, bank credentials, brokerage connection, real orders, or guaranteed returns. A production version would connect Penny’s conversation, mandate, and portfolio-orchestration layers to licensed investment advisers, brokerages, and qualified custodians.

Built for HackLanta II’s Fintech track and the Photon Agents in iMessage challenge, with meaningful Gemini API and Auth0 integrations.
